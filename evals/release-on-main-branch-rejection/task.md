# Ship a Hotfix Directly from Main

## Problem/Feature Description

A solo developer maintains a small utility library. They just committed a one-line fix directly to the `main` branch (they usually work on feature branches but were in a rush). They want to open a PR, get it reviewed, and merge it — using their standard release process. They're currently on `main` with the fix already committed.

## Output Specification

Walk through the release process for this situation. Explain each step you would take, and if any step can't proceed, explain why and what the developer should do instead.

Document your response in a file named `release-plan.md`.
