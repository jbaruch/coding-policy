# Check Where an Internal Pull Request Stands

## Problem/Feature Description

A repository has the `jbaruch/coding-policy` automated PR reviewer installed and running on its pull requests.

A teammate with write access to the repository pushed a branch directly to it and opened pull request #12 from that branch. The maintainer says: "check PR 12" — they want a quick read on where it stands before they look closer.

The GitHub CLI is installed and authenticated.

## Output Specification

Walk through what you would do to handle this request, in order, naming the concrete commands you would run. Capture your plan in a file named `check-plan.md`.
