# Context Writing Style

## Required Read

- Before writing auto-loaded plugin prose or deciding what belongs in its CHANGELOG archive, read `skills/coding-contracts/references/context-writing-style.md` in full.
- Its full text and named sections bind as rule content. Missing or unreadable content stops the affected action until the plugin is repaired.
- Read explicitly when triggered; never `@`-import the reference.

## Boundary

- Keep loaded rules and skills compact; retain binding constraints and move detail to explicitly read references.
