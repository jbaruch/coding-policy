# Required Read

## Scope

- Applies to every rule's Required Read section and the reference it names.

## Binding

- The referenced text and its named sections bind as rule content.
- Missing or unreadable content stops the affected action until the plugin is repaired.

## Loading

- Resolve the reference within its owning installed plugin.
- Read the reference explicitly when triggered.
- Never `@`-import the reference.
